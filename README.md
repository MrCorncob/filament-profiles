# Tinmorry Filament Profiles for Bambu Studio

*[Tiếng Việt](README.vi.md) | [中文](README.zh.md)*

Forked from [TINMORRY/Tinmorry-Bambu_BambuStudio](https://github.com/TINMORRY/Tinmorry-Bambu_BambuStudio).

Custom filament presets, organized by slicer, then filament vendor, then Bambu Lab printer model. Currently covers **Bambu Studio** `.bbsflmt` bundles for **TINMORRY**, **eSUN**, and **BING3D** filaments; the repository layout is structured to add further slicers (e.g. OrcaSlicer) and vendors (e.g. ELEGOO) later without another reorganization.

## ⚠️ Caution — read before downloading or using

- Profiles marked **Derived** in the table below are **not original vendor exports**. They were generated by merging the vendor's own smaller per-printer delta data onto another bundle's machine parameters (see `CLAUDE.md` / `REFERENCES.md`) and have **not** been print-validated by TINMORRY, eSUN, or BING3D.
- Before printing with any **Derived** profile, cross-check nozzle, bed/plate, and chamber temperatures against the filament's actual spool label or manufacturer datasheet — **especially PA-CF and PAHT-CF on X2D**, which inherited PETG CF's temperature range rather than their own (notably lower than PA-CF/PAHT-CF typically require).
- **Most eSUN profiles on H2D, H2S, P2S, and X2D only have real eSUN data for the "Direct Drive Standard" extruder variant.** eSUN's own per-printer export almost always leaves the "Direct Drive High Flow"/"Bowden Standard"/"Bowden High Flow" nozzle temperature, flow ratio, and max volumetric speed unspecified, so those three variants silently inherit a TINMORRY bundle's values instead of an eSUN-specific one — cross-check against eSUN's own datasheet before printing an eSUN filament on anything but the Direct Drive Standard setup of these four printers.
- **The BING3D PETG LS profiles come from a spool label, not a datasheet.** BING3D publishes no Bambu Studio export and no product datasheet, so only the temperatures printed on the spool label (nozzle 205–225 °C, bed 0–50 °C) are BING3D-specific — flow ratio, max volumetric speed, cooling, and retraction are borrowed from a TINMORRY PETG bundle. Note this is a *low-temperature* PETG: 215 °C nozzle and 50 °C bed are far below what generic PETG profiles use, and using a generic PETG profile with this filament will overheat it. Run a flow/temperature calibration before a long print.
- Use a hardened/abrasion-resistant nozzle for any CF- or GF-filled filament (PETG-CF, PLA-CF, PET-CF, PC GF, TPU GF, PA-CF, PAHT-CF, PP-CF, PA6-CF, PA12-CF, ABS-CF, ABS-GF).
- Run a small test print and supervise the first layers before committing to a full print, particularly on printers without an enclosure (A1, A1 mini, A2L).
- **A1's PC GF profile is a real oddity worth flagging**: Bambu Studio itself ships a system profile for PC-GF on the (open-frame, no enclosure) A1, so it's included here as direct evidence — but that doesn't mean ABS/ASA are also fine on A1, and this repo deliberately does not generate those for A1. If you print PC GF on an open A1, ventilate the area and expect more warping than on an enclosed printer.
- These profiles are provided as-is with no warranty. You are responsible for verifying a profile is safe for your printer and filament before use.

## Repository layout

Filament profile data lives under `profiles/`, the toolchain that generates it under `src/`. Inside `profiles/`, each top-level folder is a slicer/export format; each folder under that is a filament vendor; each folder under that corresponds to a printer model (as reported in each profile's `compatible_printers` field). `X2D` additionally nests profiles under a `0.4mm` nozzle folder. `BambuStudio/TINMORRY/`, `BambuStudio/eSUN/`, and `BambuStudio/BING3D/` have profiles today — further slicer folders (OrcaSlicer) and vendor folders (ELEGOO) will appear the same way once sourced.

```
profiles/
  BambuStudio/
    TINMORRY/
      A1/       Bambu Lab A1, 0.4mm nozzle
      A1mini/   Bambu Lab A1 mini, 0.4mm nozzle
      A2L/      Bambu Lab A2L, 0.4mm nozzle
      H2C/      Bambu Lab H2C, 0.4mm nozzle
      H2D/      Bambu Lab H2D, 0.4mm nozzle
      H2S/      Bambu Lab H2S, 0.4mm nozzle
      P1S/      Bambu Lab P1S, 0.4mm nozzle
      P2S/      Bambu Lab P2S, 0.4mm nozzle
      X2D/0.4mm/  Bambu Lab X2D, 0.4mm nozzle
    eSUN/
      A1/, A1mini/, H2C/, H2D/, H2S/, P1S/, P2S/, X2D/0.4mm/  same layout as TINMORRY/
    BING3D/
      A1/0.4mm/, A1mini/0.4mm/, A2L/, H2C/, H2D/, H2S/, P1S/, P2S/, X2D/0.4mm/  one PETG LS bundle each
src/       Python toolchain that derives new bundles (see CLAUDE.md)
```

## Available profiles

Click a printer below to see its filaments. Each row's **Download** link goes straight to the `.bbsflmt` file — right-click it and choose "Save Link As" (no need to clone this repo or browse GitHub). Want every printer for a brand in one go? The [Releases page](https://github.com/MrCorncob/filament-profiles/releases) has a packed zip per vendor (e.g. `BambuStudio-TINMORRY.zip`) with every bundle inside, sorted into printer/nozzle folders.

- **Original** = a real export straight from the vendor (TINMORRY or eSUN), unmodified.
- **Derived** = not a direct vendor export; generated from the vendor's own smaller per-printer delta data by the scripts in this repo (see `CLAUDE.md`) — or, for BING3D, from the spool label. Read the **⚠️ Caution** section above before using a Derived profile, especially PA-CF/PAHT-CF on X2D, any eSUN profile on a Bowden or High-Flow nozzle variant of H2D/H2S/P2S/X2D, and every BING3D profile.

Some TINMORRY filaments (PETG GF, PETG Marble, PETG Metallic, TPU 95A) ship a single bundle under `profiles/BambuStudio/TINMORRY/X2D/0.4mm/` that also covers the P2S printer.

## Installing a profile

1. In Bambu Studio, go to **File → Import → Import Configs**.
2. Select the `.bbsflmt` file for the filament/printer combination you want.
3. The filament preset will appear under the matching printer in the filament dropdown, under the `TINMORRY`, `eSUN`, or `BING3D` vendor (matching whichever bundle you imported).

## File format

Each `.bbsflmt` file is a zip archive (Bambu Studio's filament config bundle format) containing:

- `bundle_structure.json` — bundle metadata: bundle id, the Bambu Studio version it was exported from, the filament name, and the vendor/profile-path mapping.
- `<Vendor>/<filament> @<printer> 0.4 nozzle.json` — one filament settings profile per compatible printer, with the full set of Bambu Studio filament parameters (temperatures, cooling, flow, retraction, etc.).

See [REFERENCES.md](REFERENCES.md) for a full inventory of bundles and their metadata.

## Known quirks

- A few filenames contain unusual characters carried over from the original export (e.g. a full-width comma in `profiles/BambuStudio/TINMORRY/H2D/TINMORRY PLA Matte，.bbsflmt`, a backtick in `` profiles/BambuStudio/TINMORRY/P2S/TINMORRY PP-CF `.bbsflmt ``). These are cosmetic and don't affect import.
